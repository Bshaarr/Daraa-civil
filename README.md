# مركز الشؤون المدنية في درعا

واجهة ويب React + Vite جاهزة للنشر على Vercel.

## تشغيل محلياً

```bash
npm install
npm run dev
```

## بناء نسخة الإنتاج

```bash
npm run build
```

مجلد الإخراج هو `dist`.

## ملاحظة عن البيانات

هذه النسخة تصلح لإصلاح مشكلة الواجهة وVercel الحالية. طبقة `lib/trpc.ts` الموجودة في المشروع هي طبقة محلية مبسطة وليست اتصالاً فعلياً بقاعدة بيانات. ربط تسجيل الدخول والموظفين والإجازات وقاعدة المعرفة بقاعدة بيانات حقيقية يحتاج Backend/API فعلياً.
